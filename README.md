# Xr-linux - X Rust linux tools
Bundle of useful rust tools developed for linux systems.
The tools implement useful features for repetitive tasks.

*remark*:
    *the tools should be developed and tested on ubuntu 22.02,24.04 only*

## Install
Pull the repository and add your repository to your path:

```
git clone https://github.com/variton/xr-linux.git .

```
*remark*:
    *add to the linux PATH the path to the tool you want to use*

## Tools
The tools are folded in different directories depending on their usage.

### Unit-test-generator 
The tool generates unit test for different languages using AI models.

### Update-pkg
The cli update the packages listed with apt list --upgradable
