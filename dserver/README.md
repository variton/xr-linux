# dserver

`dserver` is a small asynchronous TCP command server written in Rust. It listens on a host and port, accepts TCP connections, reads the full request body as a shell command, executes that command with `sh -c`, and writes the command output back to the client.

## Contents

- `Cargo.toml` - Rust package metadata and dependencies.
- `Cargo.lock` - Locked dependency versions generated by Cargo.
- `src/main.rs` - Application entrypoint, CLI argument parsing, TCP listener, client handling, and command execution logic.

## How It Works

1. The server is started with a bind host and TCP port.
2. For each incoming connection, the server reads bytes until the client closes its write side.
3. The received text is trimmed and treated as a shell command.
4. The command is executed through:

   ```sh
   sh -c "<received command>"
   ```

5. If the command succeeds, stdout is returned to the client.
6. If the command fails, the server logs an error and closes the connection.

Empty requests receive:

```text
No command received
```

Successful commands that produce no stdout receive:

```text
Command completed with no output
```

## Requirements

- Rust toolchain with Cargo installed.
- A Unix-like shell environment with `sh` available.

The project uses:

- `tokio` for async networking and process execution.
- `clap` for command-line argument parsing.

## Build

```sh
cargo build
```

For an optimized release binary:

```sh
cargo build --release
```

The release binary will be created at:

```text
target/release/dserver
```

## Run

Start the server by providing a host and port:

```sh
cargo run -- --host 127.0.0.1 --port 9000
```

Short options are also available:

```sh
cargo run -- -h 127.0.0.1 -p 9000
```

After building a release binary, run it directly:

```sh
./target/release/dserver --host 127.0.0.1 --port 9000
```

## Send Commands

Use a TCP client such as `nc`:

```sh
printf 'pwd' | nc 127.0.0.1 9000
```

```sh
printf 'ls -la' | nc 127.0.0.1 9000
```

```sh
printf 'echo hello' | nc 127.0.0.1 9000
```

The server reads until the client closes the connection, so `printf` is usually more predictable than an interactive `nc` session.

## Command-Line Options

```text
--host, -h    Hostname or IP address to bind to
--port, -p    TCP port to listen on
```

Show the generated help output with:

```sh
cargo run -- --help
```

## Safety Warning

This program executes arbitrary shell commands received over TCP. Do not expose it to untrusted networks or users. Binding to `0.0.0.0` makes it reachable from other machines that can access the host, which can allow remote command execution.

For local testing, prefer binding to:

```text
127.0.0.1
```
